Visual Studios:

  Download the vim extension of Visual studios
  
  Go to C:\Users\<User>, add a new file (if not already existing) called .vimrc or _vimrc.
  
  Paste the contents of Keybinds.txt into the vimrc file.

Visual Code:

  Download the vim extension of Visual Code
  
  Extract the KeybindingsVSCode.zip and move the two files into this location C:\Users\<User>\AppData\Roaming\Code\User (!!! DO NOT MOVE THE ENTIRE FOLDER, ONLY THE TWO FILES!!!)
